HOW TO USE
1. Back up your current project folder.
2. Copy all files and folders from this package into your KGM-Microsite folder.
3. Choose Replace when asked.
4. In Terminal, inside the project folder, run:

   git add .
   git commit -m "Restore complete KGM microsite and fix lineup form"
   git push origin main

5. Wait for Vercel to finish deploying, then hard refresh with Command + Shift + R.
